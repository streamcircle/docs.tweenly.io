*Release date: 18.06.2026*

## Improvements

- **Persistent detail panel** — the graphics/asset detail panel now stays open after you save, instead of closing.
- **Context menu icons** — icons have been added to all context menus.

## Bug fixes

- **Font import:** Fixed font import when importing a graphic. Fonts with multi-word names now render correctly.
