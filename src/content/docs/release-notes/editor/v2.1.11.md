title: "Editor v2.1.11"
description: Editing fixes for selection, resizing, and data source imports, plus a missing-asset crash fix.
---

*Release date: 02.07.2026*

## Improvements

- **Destructive action warnings** — labels for destructive actions are now shown in red so they're easier to spot.

## Bug fixes

- **Data source refresh:** Refreshing a data source no longer causes graphics to glitch.
- **Data source import:** Data sources imported from a ZIP or HTML file are now correctly linked to your account.
- **Selection and alignment:** Fixed multi-select and align actions for images and text.
- **Canvas editing:** Resize and move handles now respect the canvas zoom level, and resizing now affects only the selected object.
- **Total time:** The total time value now stays in place without glitching.
- **Missing assets:** Fixed a crash that occurred when an asset was missing.
