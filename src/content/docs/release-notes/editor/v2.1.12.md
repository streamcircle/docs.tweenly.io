---
title: "Editor v2.1.12"
description: Data source and font preloading remove placeholder and fallback flashes, plus fixes for new projects and exported triggers.
---

*Release date: 16.07.2026*

## Improvements

- **Data source preload** — all bound data source assets are fetched and cached before a graphic is shown, and the canvas stays hidden until preload completes, so placeholder tokens no longer flash on first paint.
- **Unresolved data values** — when a data source request fails or a bound attribute path cannot be resolved, the canvas no longer shows `undefined`, `null` or the raw placeholder token.
- **Font preparation** — fonts are now prepared during scene and template initialization through one shared loading process, so fallback fonts no longer flash. This also covers width measurement for crawl and crawl-staggered tickers.

## Bug fixes

- **New project:** The project title field is now responsive when you create a new project, so you no longer have to cancel and start again.
- **Exported triggers:** Timeline, animation and label triggers are now invoked in an exported graphic when the timeline is updated through `window.tweenly.updateTimeline`.
- **Data source settings:** Changes made to a data source in the editor, such as the request interval or added attributes, are now reflected in the gallery.
