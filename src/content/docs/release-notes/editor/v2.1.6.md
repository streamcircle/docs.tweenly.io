*Release date: 09.04.2026*

## New features

- **Final as lock** — a graphic marked Final is now locked from editing, so a finished graphic can't be changed by accident.

## Bug fixes

- **Timeline playback:** Fixed the "next" action and "jump to" behavior during playback.
- **Labels:** Fixed label naming.
