title: "On Air v2.0.7"
description: A redesigned On Air interface with new preview actions, persistent workspace selection, and crash fixes.
---

*Release date: 02.07.2026*

## New features

- **Preview actions** — you can now show/hide and remove a graphic directly from the preview.

## Improvements

- **On Air interface redesign** — the interface has been reworked, including the main section (output and layer areas) and the left-hand graphics panel. The layout is now responsive, and input fields and selects use a filled style.
- **Persistent workspace** — the selected workspace now stays selected across page refreshes and re-login.

## Bug fixes

- **Tickers:** Up/down scrolling ticker text now updates correctly.
- **Missing assets:** Fixed a crash that occurred when an asset was missing.
