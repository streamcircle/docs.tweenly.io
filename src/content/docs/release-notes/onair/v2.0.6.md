## New features

- **Clear session** — each session now has a clear button.

## Bug fixes

- **External resources:** External and linked resources are now correctly included in live graphics.
- **Rendering:** Fixed a background rendering issue in the graphics output.
- **Stability:** Fixed a runtime error that could cause On Air to crash.
