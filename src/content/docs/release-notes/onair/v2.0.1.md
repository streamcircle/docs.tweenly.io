*Release date: 26.03.2026*

## New features

- **Final as lock** — graphics marked Final are locked in On Air. Actions and access are restricted so a finished graphic can't be changed during live operation.
- **Top navigation bar** — added a persistent top navigation bar.

## Improvements

- **Login page** — redesigned the login page.
- **Typography** — switched the interface fonts to Manrope and Inter.

## Bug fixes

- **Playback:** "Next" at the start position (0) now behaves as play.
