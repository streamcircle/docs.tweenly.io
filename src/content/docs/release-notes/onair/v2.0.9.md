---
title: "On Air v2.0.9"
description: An asset list for graphics and a layers panel empty state, plus restored scrolling in the graphics list and layers panel.
---

*Release date: 30.07.2026*

## New features

- **Graphic assets** — an icon opens a list of all assets in the graphic.

## Improvements

- **Layers panel empty state** — when a workspace has no connected layer, the layers panel shows a layers icon with the text "No layers connected" and the subtext "Connect a layer in the playout", instead of a blank area or an error message. Connecting a layer in the playout replaces the empty state with the layer section without a page refresh, and disconnecting returns the panel to the empty state.
- **Session heartbeat** — On Air keeps the playout session alive with a periodic heartbeat.
- **Data source refresh on slow connections** — the refresh interval is no longer fixed: when a request takes longer than the configured interval, refreshing continues at a slower pace instead of stopping. On very slow connections refreshing can still stall, and work on this continues.

## Bug fixes

- **Panel scrolling:** Scrolling in the graphics list and the layers panel works again, while the page as a whole still does not scroll.
