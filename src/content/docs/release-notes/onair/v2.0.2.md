## Improvements

- **Live state controls** — the play button is now hidden while a graphic is live, matching the available actions to the current state.

## Bug fixes

- **Authentication:** Fixed authentication token refresh, preventing unexpected sign-outs.
- **Graphics without animations:** Fixed a crash when a graphic has no animations on its timeline.
